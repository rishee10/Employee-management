# Demo checklist

1. Start the app (`mvn spring-boot:run` or `docker compose up --build`).
2. Open the home page and show the seeded employees.
3. Search by name (e.g. `Priya`) and filter by department / status.
4. Add a new employee and confirm redirect to the list.
5. Open **View** on an employee, then **Edit** and save.
6. Delete an employee using the confirmation modal.
7. Click **Export CSV** and open the downloaded file.
8. (Optional) Import `postman/Employee-Management.postman_collection.json` and run **List employees**.

Suggested screenshots: list page, add form, detail page, delete modal, CSV file preview.
